# هوش (Hoosh) — نسخه ۱۲.۴.۰ — ۱۴۰۵/۰۶/۲۸ (۲۰۲۶-۰۹-۱۹)

## خلاصه
راند ۲۱ — باگ‌های جدول سوپرادمین + درون‌ریزی هوشمند + مجموعه فاکتور کامل + موبایل‌فرندلی ریشه‌ای + دستیارهای هوشمند ارتقایافته + طلا/دلار + سئو.

## ⚠️ تغییرات اسکیما — الزام `bun run db:push`
- `Product.usdPrice Float?` + `Product.usdSynced Boolean` (قیمت دلاری هر کالا + همگام‌سازی)
- `Invoice.paymentType String @default("CASH")` (فاکتور قرضی/نسیه) — dueDate قبلاً موجود بود
- `BugReport.verifiedSeverity String?` (شدت تأییدشده توسط ادمین — مبنای پاداش)
- `RESERVED` وضعیت فاکتور (رزرو) — بدون تغییر enum (ستون String)

بعد از استقرار روی سرور: `bun run db:push` (بدون از دست رفتن داده — فقط ستون جدید).

## درون‌ریزی هوشمند (Task 21-A)
- CSV با انکودینگ **Windows-1256** (خروجی هلو/سپیدار) + UTF-8/UTF-16 با تشخیص خودکار
- **ادغام قیمت‌های شکسته**: «2,390,000» که در سلول‌های جدا («2»,«390»,«000») صادر شده → بازسازی هوشمند
- هدرهای واقعی هلو: «في فروش، ميانگين خريد، موجودي، گروه اصلي/فرعي، واحدهاي کالا» + ي/ك عربی
- **Excel (.xlsx/.xls) + TXT/TSV** با تشخیص جداکننده
- پیش‌نمایش + نگاشت ستون قابل تنظیم + استراتژی «رد» یا «به‌روزرسانی» SKU تکراری
- سقف: **۵۰۰۰ ردیف/درخواست، ۱۰۰,۰۰۰ ردیف/فایل** (چانک ۵۰۰تایی + نوار پیشرفت)
- **ستون موجودی** → StockItem + StockMovement (رسید تعدیل) در انبار پیش‌فرض
- گزارش نهایی کامل: created/updated/skipped/errors = مجموع کل ردیف‌ها (هیچ کالا گم نمی‌شود) + دانلود گزارش خطاها

## مجموعه فاکتور (Task 21-B)
- **ویرایش/اصلاح فاکتور**: PUT /api/invoices/[id] — قرینه سند + بازگشت موجودی + اقلام جدید + سند مجدد + audit
- **رزرو فاکتور**: ثبت بدون اثر انبار/دفتر → «ثبت نهایی» با یک کلیک (سری + فرم)
- **فاکتور قرضی (نسیه)**: paymentType CREDIT + سررسید شمسی + تب «قرضی» + «دریافت»
- **چندفاکتور**: «فاکتور بعدی (مشتری)» + شمارنده جلسه + انتخاب چندتایی + چاپ گروهی/وضعیت/حذف
- **کارتخوان**: lib/pos-terminal + /api/pos/config + «پرداخت با کارتخوان» (بریدج محلی LAN — مستند در docs/POS-INTEGRATION.md) + «ثبت دستی» fallback

## موبایل + کارایی (Task 21-C)
- **باگ ریشه‌ای پاپ‌آپ موبایل رفع شد**: پاپ‌آپ «شروع رایگان» (یوزر/پسورد تریال) گوشه‌ای/نصفه بود → حالا دقیقاً وسط و کاملاً مرئی (تأیید agent-browser). همه دیالوگ‌ها از همین مسیر درست شدند.
- حالت کارایی موبایل: حذف backdrop-blur سنگین + clamp ترنزیشن ۰.۱۵s + خاموشی انیمیشن‌های تزئینی (اسپینر/پالس حفظ)
- **ناوبری فوری**: keep-alive ۵ ماژول آخر + کش SWR (sessionStorage) — بازگشت به بخش‌ها بدون لود مجدد + رفرش مخفی پس‌زمینه
- polling اعلان/داشبورد ≥۶۰s موبایل + توقف هنگام hidden

## دستیارهای هوشمند (Task 21-D)
- **هوش‌یار (کاربر)**: ۹ ابزار جدید (مجموع ۲۳) — موجودی انبار، نرخ ارز/طلا، مطالبات قرضی با aging، ویرایش/رزرو/فاکتور قرضی، تغییر قیمت کالا، راهنما. پرامپت بازنویسی: «ممنوعیت مطلق فرافکنی» — هرگز «از پلن مدیریت درست بشه» نمی‌گوید؛ کار را انجام می‌دهد.
- **روت (سوپرادمین)**: ۸ ابزار — آمار زنده، کاربران فعال، توزیع پلن، خطر ریزش، باگ‌های باز، پرداخت‌های اخیر، سلامت سرویس‌ها، ارسال اطلاعیه (دروازه تأیید دومرحله‌ای + PlatformAuditLog). استریم SSE + جدول نتایج.
